Installation
============

Prérequis
---------

- Python >= 3.11
- Conda ou venv

Installation depuis GitHub
--------------------------

.. code-block:: bash

   git clone https://github.com/sidiso/surfh.git
   cd surfh
   pip install -e . ou pip install .

Tester l'installation
---------------------

.. code-block:: python

   import surfh
   print(surfh.__version__)
